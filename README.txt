BELLA — A LIFE IN FRAMES

Files:
- index.html: website structure + beginner-friendly JavaScript at the bottom
- style.css: all styling and responsive layout
- images/: cropped images from the collage you supplied

How to open:
1. Extract the ZIP.
2. Open the bella_editorial_site folder in VS Code.
3. Open index.html in your browser (or use Live Server).

Music:
The music button is ready for an MP3 file. Add a royalty-free audio file named music.mp3
inside the main bella_editorial_site folder. Browsers only allow audio after the visitor
clicks the music button.

Facts and counts:
The page uses the Models.com profile count visible during research: 123 magazine-cover
credits and 258 show credits. These are database entries, not a universal official total,
and can change as the profile is updated. Bella signed with IMG Models in 2014 and made
her New York Fashion Week debut for Desigual that year. Her first Vogue cover was Vogue
Turkey in 2016.
